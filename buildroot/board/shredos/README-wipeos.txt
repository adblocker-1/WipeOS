WipeOS
======

WipeOS is a bootable USB stick for securely erasing hard drives and SSDs,
with customer, technician and a PDF erasure report for every device.

!!! THIS STICK CAN IRREVERSIBLY ERASE ALL DATA ON THE DRIVES YOU SELECT !!!

How to use it: see GUIDE.txt on this stick.
Your data (settings, company logos, reports) is in the "wipeos" folder.

Project page, guide and source code:
https://github.com/adblocker-1/WipeOS

WipeOS is based on ShredOS (https://github.com/PartialVolume/shredos.x86_64)
and nwipe (https://github.com/martijnvanbrummelen/nwipe), both GNU GPL v2.
